FormFlow Embed Examples

Three ways to embed FormFlow on any website.

1. Inline Embed

<div id="my-form" style="height: 700px"></div>
<script src="/formflow-embed.js"></script>
<script>
  FormFlow.create({
    target: '#my-form',
    config: { /* your form config */ }
  });
</script>

2. Popup Embed

<button onclick="openForm()">Take Assessment</button>
<script src="/formflow-embed.js"></script>
<script>
  function openForm() {
    FormFlow.popup({
      config: { /* your form config */ },
      onSubmit: (answers) => console.log(answers)
    });
  }
</script>

3. Auto-init from JSON URL

<div data-formflow="https://your-site.com/forms/intake.json"></div>
<script src="/formflow-embed.js"></script>
